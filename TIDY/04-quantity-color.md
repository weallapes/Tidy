# TIDY — 모듈별 목표 수량 · 색상 팔레트

> 구조(00)·모듈(03) 위에서, **각 모듈에 옷을 몇 벌·무슨 색으로 채울지** 목표치를 정한다.
> = 모듈별 "캡슐 옷장" 설계. 이 목표치가 이후 부족/과잉 감사(`auditModule`)의 기준선이 된다.
> 버전: v0.1 (2026-07-06)

---

## 1. 원칙
1. **갯수는 계산한다** — 감이 아니라 `세탁주기 × 착용빈도`로 산정.
2. **계절은 모듈 내부값** — 수량도 계절별로 따로 잡는다(`INV-2`). 여름·겨울은 안 겹치므로 각각 계산.
3. **색상은 base 중심** — 무채색/기본색을 뼈대로, 포인트는 소수. 모듈끼리 팔레트가 다를 수 있다.
4. **목표는 상한선** — 이 수를 넘으면 과잉, 크게 모자라면 부족. 1-in-1-out의 기준.

---

## 2. 수량 산정 공식

```
기본형(상의·이너처럼 1회 입고 세탁):
   N = ⌈ 주당착용일 ÷ 주당세탁횟수 ⌉ + 버퍼

재착용형(하의·아우터처럼 여러 번 입고 세탁):
   N = ⌈ 주당착용일 ÷ (재착용계수 R × 주당세탁횟수) ⌉ + 1

아우터(세탁 드묾):  계절당 1~2 (형태별)
```
- **주당착용일**: 그 모듈을 그 계절에 주 몇 회 입나
- **주당세탁횟수**: 기본 1 (주 1회 세탁 가정)
- **재착용계수 R**: 하의 2~3, 니트 3~4
- **버퍼**: 오염·여벌 대비 1~2

### 2.1 확정 파라미터 ✅
| 파라미터 | 확정값 | 비고 |
|---|---|---|
| 세탁 주기 | **주 1회** | 전체 수량의 기준 |
| 회사 근무 | **주 5일 유니폼** | |
| 운동 | **주 3회** | |
| 주말 외출 | **주 2회** | |
| 등산 | **월 1~2회 (계절성)** | |
| 정장 | **월 1회 이하** | |
| 계절 구분 | **여름 / 겨울 / 간절기(봄·가을 공용)** | 3구간으로 확정 |

## 4. 색상 팔레트

### 4.1 색 구성 원리 — 70 / 20 / 10
```
Base(70%)     : 어디든 섞이는 무채색·기본색. 옷장의 뼈대.
Secondary(20%): 베이스와 잘 붙는 보조색.
Accent(10%)   : 포인트. 소수만.
```
팔레트는 `01-design` 15색에서 고른다.

### 4.2 모듈별 권장 팔레트 (제안)
| 모듈 | Base (70%) | Secondary (20%) | Accent (10%) | 메모 |
|---|---|---|---|---|
| **유니폼** | 화이트·네이비·그레이 | 블랙 | – | 격식 3(IT·규정 없음). 반팔티·폴로·반바지 OK, 스마트캐주얼 |
| **정장** | 네이비·차콜(그레이) | 화이트(셔츠) | 버건디(타이) | 클래식 |
| **주말** | 블랙·화이트·그레이·에크루 | 베이지·카키·올리브·브라운 | 러스트/오렌지 또는 올리브그린(1색·소품/아우터) | "클린 아메카지"(07). 어스톤을 secondary로 승격 |
| **운동** | 블랙·그레이 | 네이비 | 형광 1색(시인성) | 기능 우선 |
| **등산** | 카키·블랙·차콜 | 베이지 | 오렌지/레드(시인성·안전) | 아웃도어 |
| **홈웨어** | 그레이·화이트 | 네이비 | – | 편안·차분 |
| **이너** | 화이트·그레이·블랙 | 베이지(스킨) | – | 겉옷 비침 방지 |

### 4.3 색 규칙
- 각 모듈에서 **base 색 안에서는 상·하의가 서로 자유롭게 매칭**되도록(코디 고민↓).
- accent는 모듈당 **1색**으로 제한 → 난잡함 방지, 통일감.
- 이너는 겉옷 비침 고려(흰옷 밑엔 스킨/그레이).

## 5. 이 수치가 시스템에서 하는 일
```
auditModule() 기준선  : 목표 매트릭스 vs 실제 → 부족/과잉 칸 표시
정리 판단             : 과잉 칸의 저활용 옷 = 처분 1순위
구매 판단             : 부족 칸 + 팔레트에 맞는 색만 채우기 → 중복·충동구매↓
```

## 6. 확정 상태 ✅
1. **세탁 주기** → 주 1회 확정.
2. **회사 복장** → 주 5일 유니폼 확정.
3. **계절 구분** → 여름/겨울/간절기 3구간 확정.
4. **팔레트** → §4.2 제안대로 진행(추후 필요 시 재정리).
5. **총량 목표** → **103벌** 확정(target.json 실제 합계 기준).

> 목표 수량·팔레트 확정 완료. 이 값이 `auditModule()`의 기준선(baseline)이 된다.
