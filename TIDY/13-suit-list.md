# TIDY — 정장 모듈 실물 리스트

> 격식 5. 월 1회 이하(경조사·격식 자리). 컨셉과 무관한 **클래식 독립** 모듈.
> 팔레트(04): base 네이비·차콜/그레이 / secondary 화이트(셔츠) / accent 버건디(타이).
> 계절 무관(3계절 겸용 정장으로 통합) — 여름 전용 정장 불필요.
> 버전: v0.1 (2026-07-07) — 확정.

---

## 확정 (여름 포함·계절 무관)

| 역할 | 내용 | 상태 |
|---|---|---|
| 정장 셋(상하) | 미드-다크 그레이, 3계절 겸용 | ✅ 보유 |
| 구두 | 블랙 | ✅ 보유 |
| 드레스셔츠(흰) | 1 보유 + 1 추가 = 2 | 🛒 1 구매 |
| 드레스셔츠(검정) | 1 | ⚠️ 보유(스타일용) — 경조사·장례엔 부적합, 격식 코어는 흰색 |
| 넥타이 | 검정 무광 1 + 네이비 1 | 🛒 2 구매 |
| 벨트 | 블랙 가죽(구두와 매치) | 🛒 1 구매 |

### 메모
- **정장 완성 3요소 보충**: 흰 셔츠 여벌 + 넥타이 2 + 블랙 벨트 → 이걸로 경조사(장례=검정타이+흰셔츠 / 결혼·격식=네이비타이)가 커버됨.
- **버건디 타이(accent)** 는 선택 — 격식 자리 다양성 원하면 추후 1개 추가.
- 여름 격식 자리가 잦아지면 그때만 하계(경량) 정장 검토(현재 불필요).

### 구매 합계
```
흰 드레스셔츠 1 + 넥타이 2(검정·네이비) + 블랙 벨트 1 = 4점
(보유 활용: 그레이 정장, 블랙 구두, 흰셔츠1, 검정셔츠1)
```
